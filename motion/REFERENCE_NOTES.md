# 레퍼런스 메모: yihui-dev/awesome-opus5-5-videos (2026-10-10 확인)

Claude로 만든 코드 기반 모션그래픽 513편의 프롬프트 모음. 이 저장소는 학습·참고용이며 프롬프트와 영상의 권리는 각 제작자에게 있음.
그대로 복제하지 않고, 아래 제작 원칙만 이번 프로젝트에 적용한다.

## 적용할 원칙
1. **비트 맵 하나를 영상과 음악이 공유** (apoorvjain25, daniel-haida, prasenx)
   - `motion/beats.json` 하나를 HTML 렌더러와 Python 음악 합성기가 함께 읽음 → 컷·로고 조각·섬광이 같은 프레임에 소리와 맞물림
   - 음악은 Python으로 사인파와 노이즈를 합성 → 저작권 100% 깨끗함
2. **메시지와 박자를 고정한 스펙형 프롬프트** (techhalla, gdgtify)
   - 카피 순서 고정, 팔레트 고정(#FFFFFF/#00F550/#9162FF/#000), 초 단위 구간표, `render(t)`는 시간의 순수 함수
   - "조용한 정지 한 순간을 보상처럼 쓰기": 터지기 직전 0.3~0.5초 정적
3. **금지 목록으로 템플릿 느낌 차단** (twoclipping)
   - 크로스페이드, 블러 인, 의미 없는 글로우, 파티클 남발, 3D 플립 금지. 장면은 앞 장면의 형태가 변해서 넘어감(섬광 조각 → 로고 조각)
4. **로고 조각 조립 리빌** (mounnna)
   - 로고 SVG의 path 12개를 KV 섬광 조각처럼 날아와 조립 → 엔딩
5. **첫 1초 훅과 반복 재생** (reflex-cloud, ishaaqahamed)
   - 0프레임부터 움직임. 마지막 프레임이 첫 프레임과 이어지도록 설계하면 피드에서 반복 재생이 자연스러움
6. **콘택트 시트로 프레임 검수 후 한꺼번에 수정** (chapi13, aschapmann)
   - 겹침, 잘림, 읽기에 너무 짧은 텍스트를 직접 확인한 뒤에 보여줌

## 차별점
모음에 있는 작품은 전부 순수 코드 애니메이션이다. 이번 작품은 **Seedance 실사 AI 영상 + Claude 코드 모션그래픽 + 코드로 작곡한 음악**의 하이브리드로, 출품서의 'AI 기술 활용도'에서 내세울 수 있는 포인트다.
