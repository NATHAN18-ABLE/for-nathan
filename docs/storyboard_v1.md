- 규격: 1080×1920 / 30fps / 약 23초 / 120BPM 그리드(1박 = 0.5초 = 15프레임)에 컷과 타격음을 맞춤
- 톤: 애플(흰 무한 배경, 사물 하나, 정적) × 무신사(단호한 대형 타이포, 에디토리얼 그리드, 무심한 내레이션)
- 빈 화면 방지: 모든 컷에 3겹 레이어 — ① 주인공(상자, 상품, 로고) ② 대형 카피 ③ 에디토리얼 마이크로 타이포(날짜 스탬프, 인덱스 01/05, 가이드 라인, 화면 가장자리의 KV 섬광 파편). 여기에 필름 그레인을 은은하게 깖
- AI 영상: 0컷 (예비안 1컷만 보류). AI 이미지(상자 질감, 상품 컷아웃), AI 음성, Suno 음악 사용
