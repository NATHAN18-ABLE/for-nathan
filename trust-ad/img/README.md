# 이미지 교체 안내

GPT로 만든 이미지를 아래 **파일명 그대로** 이 폴더(`trust-ad/img/`)에 넣으면 페이지가 자동으로 플레이스홀더 대신 이미지를 보여 줍니다.
모든 이미지는 **1024×1024 정사각형 PNG**로 생성하세요. 페이지가 칸에 맞게 잘라서 씁니다(cover).

공통 주의: 이미지 안에 **글자, 로고, 워터마크를 넣지 마세요.** 광고 문구와 브랜드명은 페이지가 HTML로 올립니다.

| 파일명 | 크기 | 쓰이는 곳 | 화면에 보이는 크기 |
|---|---|---|---|
| `ad-hero.png` | 1024×1024 | 1·2·3·9·12단계 피드 광고, 8단계 콘솔 미리보기 | 390×390, 150×150 |
| `product.png` | 1024×1024 | 5단계 제품 썸네일, 13단계 상품 상세 | 64×64, 390×320 (위아래 잘림) |
| `feed-post.png` | 1024×1024 | 1단계 피드의 일반 게시물 | 390×300 (위아래 잘림) |
| `consumer.png` | 1024×1024 | 2·12·13단계 소비자 말풍선, 피드 프로필 | 원형 36~64px |
| `reviewer.png` | 1024×1024 | 7단계 외부 기관 연구원 | 원형 48px |
| `marketer.png` | 1024×1024 | 6~8단계 마케팅 담당자 | 원형 30~48px |

## 1. ad-hero.png — 피드 광고 메인 이미지

```
정사각형 1:1, 1024×1024 스킨케어 광고 사진.
투명한 유리 스포이트 앰플 병 하나를 화면 오른쪽 아래 1/3 지점에 배치하고,
라벨은 글자 없는 무지 화이트 라벨로 한다.
배경은 아주 밝은 하늘색에서 연회색으로 이어지는 부드러운 그라데이션,
병 주변에 작은 물방울과 투명한 젤 텍스처가 살짝 보인다.
아침 자연광, 부드러운 그림자, 상업 광고 사진 품질, 사실적인 질감.
화면 왼쪽 위 60% 영역은 큰 제목 글자를 올릴 수 있도록 아무것도 없이 밝고 깨끗하게 비워 둔다.
이미지 안에 글자, 로고, 워터마크 없음.
```
