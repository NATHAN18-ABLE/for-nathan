# 작전 회의실: 원준 커리어 본부

원준 님의 취업을 돕는 AI 팀이 일하는 픽셀아트 사무실입니다.

## 팀

| 팀 | 이름 | 하는 일 |
|---|---|---|
| 기획팀 | 한서진 | 취업 전략, 포트폴리오와 지원 아이디어 |
| 포트폴리오팀 | 정다온 | 활동 기록, 직무별로 넘치는 것과 부족한 것 판단 |
| 실행팀 | 강민석 | 영상, PPT, 포트폴리오 제작 방법을 단계별로 안내 |
| 분석팀 | 최유나 | 기업 인사팀 입장에서 나와 자소서, 활동을 평가 |
| 서치팀 | 박재윤 | AI, AI 영상, 미디어·방송·광고 업계 소식과 적용 방법 |
| 검수팀 | 이수아 | 결과물 최종 검수 (오탈자부터 "뽑을까"까지) |
| 감사팀 | 오정우 | 팀 전체 감사, 틀린 정보와 모순 잡기, 회의 최종 판정 |
| 비서 | 서윤 | 매일 아침 이슈 브리핑, 나에 대해 질문해서 프로필 채우기, 부탁 들어주기 (반말) |

## 사무실

- 팀원들은 각자 자리에서 일하다가 정수기나 커피를 마시러 가고, 서로 자리에 찾아가 얘기하고, 다시 돌아옵니다. 맡은 업무가 있으면 자리에서 일합니다.
- **팀원을 누르면 그 사람과만 1:1로 대화합니다.** 대화 기록은 팀원별로 남습니다.
  - 대화 중에 업무를 맡기면 "업무로 등록" 버튼이 뜹니다.
  - 내 경험이나 생각을 말하면 프로필의 "대화에서 알게 된 것"에 자동으로 적힙니다.
  - 비서는 그날 처음 부르면 오늘 브리핑을 전하고, 프로필의 빈칸 하나를 물어봅니다.
  - 대화 중인 Claude는 인터넷을 볼 수 없습니다. 최신 소식, 채용 공고, 마감일처럼 웹에서 확인해야 하는 질문이면 **웹으로 알아봐**를 누릅니다. 입력창에 적은 말(비어 있으면 방금 한 질문)을 클라우드 조사원에게 보내고, 5~10분 뒤 출처가 달린 답이 보고함과 그 팀원 대화에 들어옵니다. 팀원이 웹 조사가 필요하다고 판단하면 이 버튼이 노란색으로 바뀝니다.
  - 입력창은 여러 줄을 받습니다. 자기소개서처럼 긴 글은 붙여 넣으면 됩니다. Enter는 보내기, Shift+Enter는 줄바꿈입니다.
- **회의는 회의 소집을 눌렀을 때만** 열립니다. 부를 팀을 고르면 다 같이 회의 테이블로 걸어가서 브리핑, 반박, 감사 판정, 결재 순서로 진행합니다.

## 내 프로필

내 프로필 탭에 기본 정보, 목표, 경력과 활동, 콘텐츠, 자격과 툴, 지원 자료, 나라는 사람, 조건이 들어 있습니다. 모든 팀원이 이 내용을 보고 조언합니다. 직접 고칠 수 있습니다.

## 실행 방법

| 방법 | AI | 설명 |
|---|---|---|
| claude.ai 링크 | 내 Claude 계정 | 링크를 열면 바로 됩니다. 처음 쓸 때 Claude 사용, 힉스필드, Claude Code Remote(웹 조사 시작용)를 한 번씩 허용합니다. |
| 내 컴퓨터 | Claude API 키 | `boardroom/index.html`을 브라우저로 엽니다. 팀 관리 탭 → AI 연결에서 API 키를 저장합니다. 웹 조사와 정기 보고는 claude.ai 링크에서만 됩니다. |
| AI 없이 | 데모 대본 | 미리 쓴 예시 회의(예시 안건 1번)를 그대로 보여 줍니다. |

API 키는 그 브라우저에만 저장되고, Anthropic API로만 전송됩니다. 생각 깊이 설정은 빠르게(Haiku), 균형(Sonnet), 깊게(Opus)로 나뉩니다.

## 업무 (보고함)

**업무** 탭에서 팀원에게 정기 업무를 맡깁니다. 처음에는 세 가지가 들어 있습니다.

| 팀원 | 업무 | 보고 |
|---|---|---|
| 비서 서윤 | 오늘의 이슈 브리핑 (사회, 경제, AI) | 매일 아침 |
| 서치팀장 박재윤 | 주간 업계 리포트 | 매주 월요일 |
| 포트폴리오팀장 정다온 | 주간 포트폴리오 점검 | 매주 금요일 |

- **정기 보고:** Claude Code 예약 작업 "원준 커리어 본부 정기 보고"가 매일 아침 8시 52분(한국 시간)에 보고할 차례인 업무를 웹으로 조사해서 보고함에 넣습니다. 9시 전후로 들어옵니다. 앱을 열어 두지 않아도 됩니다. 하루는 아침 7시에 시작하므로, 새벽에 앱을 열어도 오늘 브리핑이 "보고할 차례"로 뜨지 않습니다.
- **웹으로 받기 (claude.ai):** 업무 옆 버튼을 누르면 같은 예약 작업을 바로 한 번 실행해서 웹으로 조사합니다. 한 번만 하는 업무를 새로 맡겨도 바로 시작합니다.
- **지금 받기 (내 컴퓨터):** 웹 검색 없이 바로 씁니다. "웹 검색 없음"으로 표시됩니다.
- 열어 둔 화면에도 새 보고가 바로 들어옵니다. 새로고침하지 않아도 됩니다.
- 새 보고가 오면 그 팀원 머리 위에 봉투가 뜹니다. 누르면 바로 열립니다.
- 예약 작업을 멈추려면 claude.ai 예약 작업 목록에서 "원준 커리어 본부 정기 보고"를 끄거나 지우면 됩니다.

## 실제 자원 (팀 관리 탭)

팀장들이 수천만 원짜리 계획을 내지 않도록, 모든 지시문에 **실제 자원**을 넣습니다.

- 실제로 일하는 사람 (기본: CEO 1명, 직원·외주 없음)
- 주당 작업 시간, 한 달 예산, 크레딧 1개 가격 (비워 두면 지금 잔액 + 100크레딧 충전 1번 안에서 계획)
- 힉스필드 요금제, 잔액, **실제로 쓴 모델별 평균 크레딧** (claude.ai에서는 회의나 보고를 시작할 때 힉스필드에서 새로 읽어 옵니다)

모든 팀장은 쉬운 말로 말하도록 지시받습니다. 전문용어는 피하고, 써야 하면 괄호로 풀어 줍니다.

## 비용

- claude.ai 링크: 내 Claude 요금제 사용량에서 차감되고 돈이 따로 나가지 않습니다.
- API 키: 회의와 보고서마다 실제로 쓴 토큰과 금액이 회의록과 보고서 아래에 표시됩니다.

## 팀장 편집

팀 관리 탭에서 다음을 바꿀 수 있습니다.

- 팀장 추가·내보내기 (최대 9명)
- 이름, 직함, 자리 명패
- 담당 분야와 판단 기준 (이 내용이 그대로 AI 지시문에 들어갑니다)
- 냉정함 1~5단계
- 외모: 피부, 머리색, 머리 모양, 정장, 소품
- 최종 판정 담당 (한 명)

팀 이름과 설명도 바꿀 수 있습니다.

## 냉정함을 만드는 장치

- 1라운드에서는 팀장끼리 서로의 의견을 보지 못하므로 분위기에 휩쓸리지 않습니다.
- 모든 지시문에 들어가는 공통 규칙: 아첨 금지, 판단마다 근거와 숫자 1개 이상, 확인되지 않은 숫자는 "(추정)", 일반론 금지, 불가능하면 불가능이라고 말할 것.
- 교전 라운드는 찬성 의견과 낙관적인 숫자를 먼저 공격합니다. 모두 찬성이면 모두가 놓친 맹점을 찾게 합니다.
- 감사팀장은 그때까지의 생존율에 끌려가지 말고 독립적으로 판정하도록 지시받습니다.
- CEO 발언에도 동의할 의무가 없고, 틀리면 반박합니다.

## 저장

- claude.ai: 내 계정 전용 저장소에 팀장 구성과 회의록이 저장됩니다.
- 내 컴퓨터: 브라우저 localStorage에 저장됩니다.

회의록은 마크다운으로 내려받거나 복사할 수 있습니다.

## 고치기

소스는 `src/`에 있습니다. 고친 뒤에는 `node boardroom/build.mjs`로 `index.html`과 `dist/boardroom.html`을 다시 만듭니다.

| 파일 | 내용 |
|---|---|
| `src/data.js` | 팀 8명, 내 프로필 기본값, 정기 업무, 예시 안건, 데모 대본 |
| `src/art.js` | 픽셀아트: 캐릭터, 회의실, 테이블, 커서 |
| `src/app.js` | 회의 진행, AI 지시문, 인사 관리, 회의록 |
| `src/office.js` | 사무실: 자리, 걸어 다니기, 회의 테이블로 모이기 |
| `src/talk.js` | 1:1 대화, 비서 체크인, 내 프로필, 회의 소집 |
| `src/work.js` | 업무, 보고함, 웹 조사 요청, 힉스필드 잔액 읽기 |
| `src/app.css`, `src/app.html` | 화면 |
